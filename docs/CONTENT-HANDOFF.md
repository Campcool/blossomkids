# 待補師資與影像：AI 接手必讀

更新：2026-10-17。業主已指示：**未補齊的師資介紹與照片先隱藏，收到並核對資料後再顯示給消費者；隱藏時一併檢查按鈕、版面與連結。** 本規則取代舊版「維持所有灰色佔位」或「隱藏需再等業主點頭」的相關描述；收費、名額等其他待確認資訊不在這次隱藏範圍。

## 後續 AI 必須提醒業主補件

每次接手相關內容維護時，先讀本表及 `lib/content-visibility.ts`，確認是否已有新附件或來源。若仍未提供，向業主簡短列出尚缺項目並提醒補件；不要求業主重新授權目前已決定的隱藏策略，也不要為了提醒而重新把佔位卡顯示給訪客。這是交接時的工作要求，不是已建立定時通知。

## 保留的已提供內容

- 校園頁六張現有實拍：寢具、不鏽鋼餐具、廚房紗門、煮沸飲水、洗手空間及廁所分隔。
- 現有已打碼第 30 屆畢業照與既有安全／園所資料。年份與原始授權仍按原交接資料核對，不可因檔案存在就自行宣稱已取得全部授權。
- 品牌插畫與課程示意圖維持明確標註；不替代實拍證據。
- 招生、收費、名額、保險等必要的待確認狀態維持原有說明，不能把未知內容改成已確認。

## 發布方式與驗收

1. `lib/content-visibility.ts` 是師資／活動區與入口共用的發布開關，目前都為 `false`。使用伺服器條件渲染，不是 `display:none`；未備妥的內容不進公開 HTML，也不留空的區塊、標題或可點入口。
2. **開關不是「有照片就打開」的捷徑。** 先核對來源、授權與個資，替換該區所有 `PhotoSlot`／假設資料。若只補齊一位老師或一則活動，只渲染那一筆，不補空卡湊欄。
3. 重新檢查首頁卡片、頁內導覽、metadata 描述與跨頁 `#team`／`#stories` 連結；不可出現指向沒有內容或被隱藏節點的按鈕。已移除的舊網址 fragment 不代表有公開內容，不為了保留 fragment 建空區塊。
4. 補件後更新本表狀態／來源與日期，並同步 README、AI-README。不要把私有證件、同意書或未去識別影像放進 public 或 GitHub。
5. 改中文後重產字型；執行 `npx tsc --noEmit`、`STATIC_EXPORT=1 npm run build:static`、`npm test`、`npm run lint`、`npm run test:browser`。瀏覽器檢查會驗所有內部 fragment 指向可見內容，且不允許公開頁出現 `maintenance-slot`。有資料後不應放寬這項檢查，而應換成實際內容。
6. 檢視 320／390／768／1440：無空照片框、空欄、橫向溢出、遮擋或壞圖；電話、LINE、地圖與預約仍可用。既有合法照片不可因隱藏佔位而消失。
