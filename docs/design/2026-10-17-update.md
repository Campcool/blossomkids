日期：2026-10-17（Asia/Taipei）
分支：`codex/kindergarten-reading-20261017`

## 目的與方向

讓第一次選園的家長，以「溫暖的幼兒園探索手冊」認識服務、學習與日常，再找到環境、費用和預約入口。園所事實沿用 `lib/site-data.ts`、README 與既有頁面；設計沿用 `DESIGN.md`。正式平台維持 GitHub Pages 的 `out/`，沒有變更 DNS 或 Sites 綁定。

來源：Campcool/AI-skill `c91e2509f1888a11cf6c0073a5d9c333c5ed47a3`（2026-10-17 查核 `origin/main`），`uiux-design/SKILL.md` 與 `playbooks/design-skills-integration.md`。

- Taste：首頁採左右開場與紙藝繪本主視覺，服務、主題、時程、實景與問答交替排列。
- Impeccable 的 read/persuade、clarify/audit 方法：段落捷徑、清楚分句、較短的服務卡、安靜的時程列，以及圖片／表單狀態的誠實標示。未執行完整 engine、hooks 或 detector，不宣稱工具認證。

- Emil：不新增動效依賴；減少無意義的循環裝飾。原生 details、穩定手機字級、reduced-motion 及可觸控導覽優先。

## 內容與功能

- 首頁加入原創紙藝繪本 WebP，約 124 KiB；清楚標示「品牌主題插畫・非園所實景」。完整生成 prompt 存於 `paper-garden-source.json`。
- 首頁與幼兒園頁新增三個主題：繪本與表達、自然與觀察、美感與創作；每個主題可展開親子活動，清楚區分提案與園內實際課程。
- 七個主要頁面加入原生段落導覽；手機兩欄排列，不增加固定導覽列。
- 服務卡、班別圖文、時程、段落間距與標題建立一致閱讀節奏。課程情境圖加上示意說明。
- 招生流程文案說明需透過 LINE／電話與園方確認；既有表單仍僅整理訊息，不會自動上傳。修正頁首 LINE 的無障礙名稱。
- 保留尚待園方補齊的資料、既有打碼畢業照、電話、地址與個人 LINE 契約。重產 Iansui 字型子集。

## 可重跑驗證

```sh
npm ci
npx tsc --noEmit
STATIC_EXPORT=1 npm run build:static
npm test
npm run lint
npx playwright install --with-deps chromium
npm run test:browser
```

如使用已安裝的 Chromium，可指定 `CHROMIUM_PATH=/usr/bin/chromium`。瀏覽器報告與截圖預設存於 `outputs/editorial/`（不隨網站發布）。測試的本機伺服器先選 `/route.html`，再選資料夾 index，避免把 Next 16 的 RSC payload 資料夾誤當 HTML 頁面。

`test:browser` 驗證 8 頁 × 4 寬度（320／390／768／1440）、圖片、字型、整頁溢位、段落目的地、44px 段落入口、網站分頁、鍵盤展開、手機錨點、預約訊息整理及無 JS 的聯絡／展開功能。外部地圖 iframe 在測試中隔離；只核對 LINE／電話網址，不宣稱實際送達、真機、Safari、Firefox 或 Lighthouse 成績。

CI 的 PR 檢查與部署 build job 都在 `npm test` 後跑 Chromium 檢查，部署必須通過同一條相依鏈才會上傳 `out/`。這是互動及版面斷言，並非像素差異比對。
